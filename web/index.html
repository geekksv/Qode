How it works

Every other generator sends your data to a server. This one doesn't.

A QR code is just an encoding — turning text into a grid of black and white squares. It needs no account, no cloud, and no subscription. Qode does that maths in your browser, so the thing you type never leaves the machine you typed it on.

A real encoder, compiled to WebAssembly

The ISO/IEC 18004 encoder behind this page is written from scratch in Go — Reed–Solomon error correction, all eight mask patterns, versions 1 through 40 — and compiled to WebAssembly. Its output is verified module-for-module against a reference implementation, including at version 40's maximum capacity.

Nothing is stored, so nothing can leak or expire

Wi-Fi passwords, private phone numbers, wallet addresses, unpublished links — none of it is transmitted anywhere. There is no database recording where your codes point, which also means no scan tracking, no rate limit, and no account that can lapse and break something you already printed.

True vector output, free

The SVG download is real geometry, not a traced bitmap, so it stays sharp on a business card and on a billboard. Most generators put vector export behind a paid tier and hand you a low-resolution PNG otherwise.

Fifteen types, and what each one actually encodes

Most types write a standard URI straight into the code, so the phone acts on it with no internet connection at all. Two of them — App and Social — need a page to make a decision, so they carry their payload in a URL fragment, which browsers never transmit to a server.

Before you print a thousand of them

A QR code that fails in the field is expensive in a way an on-screen one never is. These are the failures worth ruling out first.

  • Scan the actual print, not the screen. Ink spread, paper texture and matte lamination all cost you contrast that a monitor hides.
  • Keep dark modules on a light background. Inverted codes look striking and fail on most phone cameras — the studio warns you when contrast drops too far.
  • Leave the quiet zone alone. Four modules of blank margin is the ISO minimum, and it's the first thing a designer tends to crop away.
  • Shorter content means chunkier modules. A long URL pushes the version up and the squares down, which is what limits scanning distance.
  • Rule of thumb for size: the printed code wants to be roughly a tenth of the distance it will be scanned from. Across a room means bigger than you think.
  • Test on both an iPhone and an Android before committing. Their scanners disagree about edge cases more often than you'd expect.

Questions

Do these codes expire?

No, and they can't. A standard QR code is a self-contained encoding — the content is the code. There is no lookup, no redirect service, and no account behind it, so there is nothing that can be switched off. Codes generated here will still scan in ten years whether or not this site exists.

Is there a scan limit, or a watermark?

Neither. Scanning happens entirely between the phone and the printed code — Qode isn't involved and couldn't count it. Downloads are unwatermarked PNG and SVG at any volume.

Can I edit a code after printing it?

Yes, using the Dynamic Link wizard. It points your code at a free page you already control — a Notion page, a published Google Doc, a Linktree — so you edit that page instead of reprinting. Competitors charge a subscription for this because they use a server to remember the destination; Qode puts the destination in the URL fragment, which browsers never send to any server.

Why does adding a logo change the error-correction level?

A logo physically covers modules that carry real data. Level H reserves about 30% of the code for recovery, so the scanner reconstructs what the logo hides. The studio switches to H automatically when you attach one, and keeps the logo's coverage constant as you resize it — a wide wordmark and a square icon obscure the same number of modules at the same setting.

Which format should I download?

SVG for anything going to print or into a design tool — it's real vector geometry and scales without limit. PNG at 1200 px for slides, documents and the web. When in doubt, take the SVG; you can always rasterise it later, but you can't go the other way.

Can I generate hundreds at once?

Yes — the Bulk page takes a CSV, generates a code per row and bundles them into a ZIP, as PNG or SVG. There's no row limit, and the file is parsed in the browser rather than uploaded.
