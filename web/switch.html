Change where a printed code goes.
As often as you like.

Give a code a short name, and it becomes a permanent address at /go/<name>. The name is the part that gets printed; the destination behind it is yours to change whenever you want. Bitly rations this to five changes a month — here it is one line in one file.

Which one do you want?

Switchable — the code opens a different URL whenever you decide. Use it when the destination itself may move.

Dynamic Link — the code always opens the same page, and you edit what is on that page. It scans slightly faster and keeps working even if this site disappears. Prefer it when the destination is settled.

Worth knowing

Never rename or delete a live name. The name is the part physically on the paper. Change it and every code carrying it stops working, and no amount of editing brings those back — only reprinting does.

These codes depend on this site. They point at /go/<name> here, so if this domain goes away they stop resolving. The other sixteen content types carry their destination inside them and have no such dependency.

Only someone who can push to this project can change a destination. There is no login here because there is nothing to log in to — which is also why there is nothing to rate-limit, nothing to leak, and no account that can lapse.

Qode — free, forever. One file, no database, and no account that can expire and take your printed codes with it.
