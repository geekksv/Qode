    How this works without a server

    Your code encodes a Qode /r address with the destination packed into the URL's fragment — the part after the #. Browsers never transmit a fragment to any server, so the redirect page decodes it locally, in the visitor's own browser.

    The practical consequence: Qode has no record of where any code points, there is nothing to expire, nothing to rate-limit, and no account that can lapse and break your printed material.

    Qode never stores or sees the destination you choose — it's encoded into the QR code itself.
